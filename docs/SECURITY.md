# LeagueDesk 安全与授权边界

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2

服务端会话采用HttpOnly、SameSite=Strict，30分钟闲置过期；正式TLS部署应启用Secure。登录更新会话ID，CSRF保护写入，失败登录按用户名与来源地址限速。密码BCrypt存储，不返回Hash。API每次检查账号、组织与当前角色；已有会话的密码散列与最新密码不同即失效。权限和数据范围由服务端验证，菜单只是入口。

命令UUID绑定操作者、动作、完整载荷；相同请求返回当前记录，不产生重复晋级。记录版本拒绝过时提交；数据库事务与写锁防止并发重复抽签或最后管理员降权。串行策略减少竞态，不适合无限吞吐。事务失败不保留部分结果。

公众只读API构造独立字段视图。只有已发布且非草稿赛事可访问，不含负责人账号ID、联系人、私有报名备注、裁判账号ID或审计。参赛角色只读取本人私有报名和获批显示名；裁判只进入本人已指派赛事。公开显示名与说明必须由主办方审慎选择，不能填入敏感资料。取消发布使后续API不可访问，但不能撤回外部已保存的截图或资料。

CSV公式前缀安全转义；不向业务导出、JSON返回值和日志插入推广内容。会话和API无缓存，Nginx配置CSP、禁止frame、nosniff。`.env`、数据库快照、构建输出不入Git，截图使用标记TEST的非客户数据。备份明文包含密码散列，应加密存储。

未做外部渗透、安全审计或大规模性能认证。正式公网使用前应进行风险评估、更新依赖、设置HTTPS与反向代理限流、监控备份；不将源码许可或本机测试理解为合规认证。商业使用先获得书面授权，许可与品牌联系方式是独立事项。

# LeagueDesk 业务范围

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2

单经营主体、多组织的球类赛事管理。参赛单位可为个人或团队的一个比赛报名单位，每个报名绑定一个负责人账号；系统记录比赛双方胜局数，不记录队内单打双打编排或逐球计分。主办方管理赛季、场地、赛事、报名审核与签到；负责人使用本人登录报名和撤回；裁判仅可录入本人被指派比赛。公众只看已发布赛事的参赛显示名、赛程、成绩与小组排名，不读取联系人或账号。

DRAFT → OPEN → GROUP（循环赛）→ KNOCKOUT → FINISHED；直接淘汰赛从OPEN进入KNOCKOUT。分组按照公开种子顺序蛇形分配；小组按胜场、净胜局、胜局数、种子序排序，晋级数量为赛事预先冻结参数。淘汰赛首轮按排名顺序与末位配对，补足2的幂次轮空。仅完整小组结果才可生成淘汰，已生成下游阶段后不允许更正小组结果；淘汰结果更正前，所有下游比赛必须尚未开始。所有更正保留旧新比分、操作者与理由。

赛程必须有已启用场地、裁判及起止时间；跨赛事检查场地、裁判和已确定参赛账号重叠。下游参与者确定后再次检查排赛冲突。赛事只能在全部淘汰结果确定后完成；冠军5分、亚军3分、其他实际入签参赛单位1分，赛季积分累加已完成赛事。积分为本地规则，不是官方排名。账号停用、组织停用和角色修改立即影响权限，公开页面可随时取消发布。

核心业务无外部服务依赖；首版不含短信、费用支付、联邦排名、硬件计分、视频直播、自动智能排程、离线同步、多公司SaaS。演示资料只来自明确标记的测试录入，空库仅初始化管理员与目录。
